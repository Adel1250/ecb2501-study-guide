# ECB2501 Study Guide

A friendly, step-by-step study website for **ECB2501 – Material Science & Properties**.

It covers:

| Page | Content |
|---|---|
| Math toolkit | The 4 math tools needed for the course |
| Lecture 1 | Introduction to materials science and engineering |
| Lecture 2 | Atomic structure (review) |
| Lecture 3 + Section 2 | Interatomic bonding, bonding forces and energies |
| Lecture 4 + Sections 3 & 4 | Crystal structures, unit cells, APF, density, HCP c/a proof |
| Cheat sheet | Every formula on one page, plus a final quiz |

Every page has interactive diagrams, checkpoint quizzes after each part, and a summary.

It's a plain static site (HTML, CSS and JavaScript, no build step), hosted with GitHub Pages.
To preview it locally, open `index.html` in a browser.
