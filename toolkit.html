Step 0

The math toolkit 🛠

Only 4 tools. That's honestly all the math Lectures 1–4 and Sections 2–4 need. If they feel easy, skip ahead.

🛠 Tool 1: negative powers

A negative power just means "one over":

1r = r−1     1r2 = r−2     Brn = B·r−n

So −A/r is the same as −A·r−1. We rewrite things this way because it makes derivatives easy.

Same idea for tiny numbers: 10−9 = 1/1,000,000,000. That's why 1 nm = 10−9 m.

🛠 Tool 2: the power rule for derivatives

A derivative tells you the slope of a curve, meaning how steep it is at a point. The one rule you need:

d/dr ( rk ) = k · rk−1

In words: bring the power down in front, then subtract 1 from the power.

Try it:
d/dr ( −A·r−1 ) = −A · (−1) · r−2 = +A·r−2 = Ar2
d/dr ( B·r−n ) = B · (−n) · r−n−1 = −nBrn+1
Watch the signs: (−1)×(−A) = +A. Most mistakes in Section 2 happen right here.
⭐ Why derivatives matter At the very bottom of a valley, the ground is flat, so the slope = 0. To find the lowest point of any curve: take the derivative, set it equal to 0, solve. That's the whole trick in the Section 2 problem.

🛠 Tool 3: rules for powers

rarb = ra−b     (ra)b = rab     if xp = Q  then  x = Q1/p

Examples:

  • r2/rn+1 = r2−(n+1) = r1−n
  • If r1−n = 5, then r = 51/(1−n)
  • (0.143 × 10−9)3 = 0.1433 × 10−27: cube the number and the power of ten (−9 × 3 = −27).

🛠 Tool 4: Pythagoras (in 2D and 3D)

For a right triangle: (long side)² = (side 1)² + (side 2)². Apply it to a cube of side a:

  • Face diagonal: a² + a² = 2a² → length a√2
  • Body diagonal: (face diagonal)² + a² = 2a² + a² = 3a² → length a√3

Remember √2 ≈ 1.414 and √3 ≈ 1.732.

🎁 Bonus: two tiny trig facts (for Section 4)

  • In a right triangle, cos(angle) = adjacent side / hypotenuse.
  • cos 30° = √3/2 ≈ 0.866

And the volume of a ball (sphere): V = (4/3)πR³. That's it, the toolkit is done. 🎉
